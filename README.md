# Funngro Website Revamp

A responsive redesign of the Funngro website featuring separate landing pages for teens and companies.

## Pages
- `index.html` — Teens landing page
- `company.html` — Companies landing page

## Features
- Responsive layout for desktop and mobile
- Mobile navigation menu
- Interactive FAQ accordions
- SEO metadata and semantic HTML
- `robots.txt` and `sitemap.xml`

## Technologies
- HTML5
- CSS3
- Vanilla JavaScript

## Run Locally
Download or clone this repository and open `index.html` in your browser.

## Deployment
Deployed using Netlify.

## Note
This is a website redesign project created for learning and evaluation purposes. It is not the official Funngro website.
